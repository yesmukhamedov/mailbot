# mailbot

Чтение и отправка рабочей почты из терминала (или из агента вроде Claude Code) **через веб-интерфейс
Outlook**, без Microsoft Graph.

Зачем: во многих корпоративных и университетских тенантах Graph API закрыт — приложению нужен
admin consent, которого администратор не даёт. Но веб-почта в браузере при этом работает. mailbot
поднимает установленный Chrome под управлением Playwright с постоянным профилем: вы один раз
входите руками, дальше скрипты читают и отправляют письма фоново, без открытия окна.

## Установка

```bash
git clone https://github.com/yesmukhamedov/mailbot.git
cd mailbot
npm install
```

Нужны Node.js >= 20.6 и установленный Chrome (используется системный, отдельный браузер Playwright
не скачивается).

По желанию: `cp .env.example .env` и поправьте пути — по умолчанию всё работает из папки проекта.

## Использование

```bash
# Разовый вход: откроется видимое окно Chrome, логин и пароль вводите вы.
# Отметьте «Остаться в системе» — сессия сохранится в profile/.
node login.js

# Прочитать 10 последних входящих (JSON в stdout)
node read.js 10

# Другие папки: sentitems, drafts, archive, junkemail
node read.js 5 sentitems

# Подготовить письмо и сделать скриншот, НЕ отправляя
node send.js --to кому@домен --subject "Тема" --body "Текст" --dry-run

# Отправить
node send.js --to кому@домен --subject "Тема" --body "Текст"
```

## Файлы

| Файл | Назначение |
|---|---|
| `lib.js` | запуск Chrome с постоянным профилем, конфиг, проверка входа |
| `login.js` | разовый вход, сохранение сессии |
| `read.js` | чтение писем, вывод JSON |
| `send.js` | отправка, `--dry-run` + скриншот черновика |
| `profile/` | профиль Chrome с сессией — создаётся при первом входе, **в git не попадает** |

## Настройки

Через переменные окружения или `.env` (см. `.env.example`):

| Переменная | По умолчанию |
|---|---|
| `MAILBOT_PROFILE` | `./profile` |
| `MAILBOT_MAIL_URL` | `https://outlook.office.com/mail/` |
| `MAILBOT_SCREENSHOT` | `./draft.png` |

## Безопасность

- **`profile/` — это фактически доступ к вашему ящику.** Папка содержит куки живой сессии; кто её
  получил, тот читает и отправляет почту от вашего имени. Она в `.gitignore`, держите её так.
- Скриншоты (`draft.png` и любые `*.png`) тоже в `.gitignore` — на них видны адреса и текст писем.
- Пароль скриптам не передаётся и нигде не хранится: его вводите только вы в окне Chrome.
- Инструмент работает от вашего лица в вашем ящике. Используйте только там, где это допускает
  политика вашей организации.

## Если перестало работать

Скрипт вернул `{"error":"NOT_SIGNED_IN"}` — сессия истекла (обычно раз в ~90 дней или после смены
пароля). Запустите `node login.js` и войдите заново.

Селекторы завязаны на разметку веб-Outlook, поэтому после редизайна интерфейса Microsoft что-то
может отвалиться — правится в `lib.js` (`isSignedIn`) и `read.js`/`send.js`.
